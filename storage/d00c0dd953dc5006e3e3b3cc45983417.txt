⚠ KENAPA GAK WORK?
Browser punya 4 layer proteksi yang blokir request ke NGL:
1. CORS Policy — NGL tidak kirim header Access-Control-Allow-Origin, jadi fetch dari domain/localhost/file:// diblokir browser
2. Origin/Referer Validation — Browser auto-set Origin ke domain kamu (bukan ngl.link). Header ini forbidden, gak bisa di-override
3. Cloudflare Bot Protection — Tanpa cookie cf_clearance, request di-challenge
4. deviceId Format — Aslinya UUID v4 (36 char), bukan 42 hex random
